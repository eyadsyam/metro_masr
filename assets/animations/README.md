# Rive Animations Folder

## 📁 This folder is ready for your Rive animation files

### How to add animations:

1. Visit [Rive Community](https://rive.app/community)
2. Download free `.riv` animation files
3. Place them in this folder

### Recommended files:
- `metro_train.riv` - Metro train animation for home screen
- `loading.riv` - Loading spinner for route calculation
- `success.riv` - Success checkmark for confirmations
- `empty_state.riv` - Empty state illustration

### File size recommendations:
- Keep each file under 100KB for best performance
- Optimize animations in Rive editor before exporting

See `RIVE_SETUP_GUIDE.md` in the project root for detailed instructions.
